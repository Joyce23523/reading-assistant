## One Concept Explained

- **Concept / 概念**：多模型代理工作是指协调多个专精 AI 模型协同完成任务的架构，而非单一模型独自运作。
- **Plain explanation / 直白解释**：这种模式下，系统像一个由不同专长的智能体组成的团队，分工协作完成复杂任务，例如跨模型数据分析、多模态内容生成等。
- **Why it matters / 意义**：在教育场景中，这提升了教学自动化的潜力，但也要求学生与教师具备更高的 prompt literacy 与模型输出验证能力，以辨别结果的可靠性、防止幻觉并确保学术诚信与伦理合规。
