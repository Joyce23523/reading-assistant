## One Concept Explained

- **Concept / 概念**：Zero Data Retention（零数据保留）是 OpenAI 为符合条件的 API 客户提供的政策，确保模型训练后不存储输入输出数据。
- **Plain explanation / 直白解释**：相当于用户数据在服务结束后立即被清除，防止长期存储带来的隐私风险。
- **Why it matters / 意义**：对国际学校采用 AI 工具时数据合规性要求极高，Zero Data Retention 提供了一个可参考的隐私保护模型。
