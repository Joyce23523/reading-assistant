# Morning Intelligence Briefing｜2026-07-19

## Top 3 Tech & AI Stories

### 1. OpenAI introduces "A scorecard for the AI age"
- **发生了什么**：OpenAI CFO Sarah Friar 提出一个实用 AI scorecard，用 useful work、cost per successful task、dependability、return on compute 衡量 ROI。
- **为什么重要**：将 AI 价值评估从叙事拉向可量化指标，反映企业侧对 accountability 和 compute economics 的结构性需求。
- **对我有什么意义**：国际学校管理层可观察 vendor 是否用类似 scorecard 汇报 edtech ROI；长期追踪 AI governance 时，把 "return on compute" 作为基础设施约束观察点。
- **Source**：OpenAI Blog，2026-07-17，https://openai.com/index/a-scorecard-for-the-ai-age

### 2. OpenAI: "Why teens deserve access to safe AI"
- **发生了什么**：OpenAI 说明正在为 ChatGPT 加入 age-appropriate protections、learning tools、parental controls 与 expert partnerships。
- **为什么重要**：未成年人 AI access 正从禁令逻辑转向 safe-by-design + parental oversight，是教育场景治理的基础设施信号。
- **对我有什么意义**：A-Level 学生未来能力画像应包含 verification 与 prompt literacy；可迁移做法是学校制定 teen AI use policy 时参考 parental controls 框架。
- **Source**：OpenAI Blog，2026-07-17，https://openai.com/index/why-teens-deserve-access-safe-ai

### 3. Google: Expanding Managed Agents in Gemini API
- **发生了什么**：Google 扩展 Gemini API 的 Managed agents，加入 background tasks、remote MCP 等能力。
- **为什么重要**：agentic workflow 正从 demo 进入 API 基础设施层，改变知识工作的 automation 边界。
- **对我有什么意义**：Joyce 的 personal knowledge system 可关注 remote MCP 作为跨源 reading system 的潜在连接器；长期观察 AI agents 对国际课程行政流程的替代度。
- **Source**：Google AI Blog，2026-07-07，https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api/

## One Concept Explained

- **Concept / 概念**：Return on compute
- **Plain explanation / 直白解释**：每单位算力投入带来的有效产出，用于衡量 AI 系统是否划算。
- **Why it matters / 意义**：它把 AI 从“能做事”推向“算得过账”，是学校与企业在采用模型时的硬约束。
