# Morning Intelligence Briefing｜2026-08-20

### 1. OpenAI Zero Data Retention for Frontier Models
- **发生了什么**：OpenAI 重申对符合条件的 API 客户提供 Zero Data Retention，并预览 Private Safety Processing，以在不泄露数据隐私的前提下提升 AI 安全。
- **为什么重要**：体现 AI 治理向数据主权与隐私保护的制度转向，为教育机构使用 AI API 提供合规与信任基准。
- **对我有什么意义**：可观察学校在使用 AI 服务时的数据管理实践，评估 Prompt 与数据输入的安全性，并规划符合隐私要求的教学流程。
- **Source**：OpenAI Blog, 2026-08-20 https://openai.com/index/offering-zero-data-retention-for-frontier-models

### 2. Replit Free Mode with GPT-5.6 Luna
- **发生了什么**：Replit 推出免费模式，基于 GPT-5.6 Luna，使用户无需考虑 token 费用即可将创意转化为可运行软件。
- **为什么重要**：降低软件创作门槛，推动教育环境中编程与自动化工作流的普及，影响学生的技术素养培养。
- **对我有什么意义**：可监测学校编程俱乐部或跨学科项目采用低成本 AI 开发工具的趋势，评估其对学生能力画像的影响。
- **Source**：OpenAI Blog, 2026-08-19 https://openai.com/index/replit

### 3. Google Search Learning Tools (Add Notebook, Ask Google)
- **发生了什么**：Google Search 推出 5 种提升学习的方式，包括“Add Notebook”和“Ask Google”等功能，以帮助学生更高效地组织与检索信息。
- **为什么重要**：强化学生的信息整理与批判性思维能力，契合 A-Level/国际课程对数据素养与研究技巧的要求。
- **对我有什么意义**：可观察教学中将搜索工具嵌入课堂工作流的可行性，评估学生的 prompt 与信息验证能力提升情况。
- **Source**：Google AI Blog, 2026-08-20 https://blog.google/products-and-platforms/products/search/back-to-school-study-tools/

## One Concept Explained
- **Concept / 概念**：Zero Data Retention (零数据留存)
- **Plain explanation / 直白解释**：在不泄露用户数据的前提下，AI 提供可选的数据保留政策，允许机构自行决定是否保留交互记录，从而兼顾数据隐私与模型安全。
- **Why it matters / 意义**：这使得学校在使用 AI API 时确保学生隐私合规，降低因数据泄露导致的法律与信任风险，并为教学活动提供更可控的技术环境。这有助于学生在数字世界中保持安全与批判性思维。
