## Top 3 Tech & AI Stories
### 1. OpenAI launches Health in ChatGPT for U.S. users
- **发生了什么**：Health in ChatGPT 允许符合条件的美国用户安全连接电子病历和 Apple Health，获得个性化健康洞察。
- **为什么重要**：这是 AI agent 接入个人敏感数据的基础设施案例，涉及 data sovereignty、consent 与 HIPAA-adjacent 治理框架，对 AI 在受监管行业的落地有信号意义。
- **对我有什么意义**：可观察国际学校健康管理 / 校医数字化的潜在接口；A-Level / IAL 学生未来需具备 health data verification、prompt literacy 与 cybersecurity awareness；长期追踪 AI governance 在教育场景的边界。Source limitation：来源未涉及教育场景。
- **Source**：OpenAI Blog, 2026-07-23, https://openai.com/index/health-in-chatgpt

### 2. OpenAI announces Project Camellia in Effingham County, Georgia
- **发生了什么**：OpenAI 与 Effingham County 合作推进 Project Camellia，承诺负责任能源、社区投资、就业岗位与 Codex 接入。
- **为什么重要**：AI infrastructure 落地从超大规模数据中心向县域社区扩散，涉及能源结构、地方激励与 workforce pipeline，是 sovereign cloud / domestic buildout 趋势的缩影。
- **对我有什么意义**：可追踪国际学校所在区域是否被纳入 AI infrastructure 规划；学校管理层需关注本地 AI 就业与人才管道对 admissions / 课程合作的影响；Codex 接入对学生 computational thinking 与 AI-assisted coding 能力培养有长期参考价值。Source limitation：来源未直接关联教育。
- **Source**：OpenAI Blog, 2026-07-22, https://openai.com/index/building-ai-infrastructure-with-the-effingham-county-community

### 3. Microsoft commits $60 million to DOE Genesis Mission
- **发生了什么**：Microsoft 长期承诺支持美国能源部 Genesis Mission，加速 AI for science 的突破。
- **为什么重要**：国家级 AI for science 投入叠加 Azure AI / HPC 与 AMD 合作，反映 compute、infrastructure 与科研资助的绑定加深，地缘科技竞争维度强化。
- **对我有什么意义**：可观察国际学校 STEM / research 合作机会是否向 DOE national labs 延伸；A-Level 学生未来能力画像需包含 AI-assisted scientific reasoning 与 data verification；长期追踪美国科技政策对国际课程 STEM 路径的影响。Source limitation：来源未涉及教育。
- **Source**：Microsoft Blog, 2026-07-22, https://blogs.microsoft.com/blog/2026/07/22/powering-americas-genesis-mission-microsofts-commitment-to-scientific-discovery/

## One Concept Explained
- **Concept / 概念**：sovereign cloud
- **Plain explanation / 直白解释**：数据与算力留在本国或特定区域，由本地法律管辖，降低跨境数据流动风险。
- **Why it matters / 意义**：影响国际学校数据存储、AI 工具选型与跨境教学协作的合规边界。
