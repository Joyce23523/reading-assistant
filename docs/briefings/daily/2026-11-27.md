### 1. GPT-6 models demonstrate intrinsic protein-design capabilities
- **发生了什么**：OpenAI 称 GPT-6 models 可用 reasoning 和 code 设计 protein structures and sequences；lab tests 在 five targets 发现 binding evidence。
- **为什么重要**：结构性判断：AI 正从文本/代码生成进入生物设计环节，研发流程可能把 model reasoning、代码执行与实验验证连成一条链。
- **对我有什么意义**：长期观察 AI governance 与科学自动化：学校管理层可把“生成—验证—留痕”作为 AI 项目门槛；学生能力画像加入 verification、prompt literacy、cybersecurity awareness。Source limitations：来源未说明实验可复现性与监管路径。
- **Source**：OpenAI Blog, 2026-11-24, https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities

### 2. How iFood scales coding agents across 15,000 repositories
- **发生了什么**：OpenAI 发布 iFood 案例，称其将 coding agents 扩展到 15,000 个 repositories。
- **为什么重要**：结构性判断：coding agents 从单点试点走向组织级部署，核心约束会转向权限、审计、代码质量与 automation workflow 治理。
- **对我有什么意义**：可迁移到国际学校 IT/知识工作：观察 agent 是否具备 sandboxing、最小权限、日志追踪与人工复核；学生需理解 AI agents 的 cybersecurity awareness。Source limitations：摘要为空，具体架构与风险控制未知。
- **Source**：OpenAI Blog, 2026-11-24, https://openai.com/business/customer-stories/ifood

## One Concept Explained

- **Concept / 概念**：coding agents
- **Plain explanation / 直白解释**：Coding agents 是能读取代码库、修改文件、运行测试并提交变更的 AI 代理。它们把 AI 从补全代码推进到执行任务，但依赖权限、日志、sandboxing 与人工复核。
- **Why it matters / 意义**：这类自动化会进入学校 IT、招生系统和知识管理。越自动，越需要 verification、cybersecurity awareness 和 Trusted Access 边界；对长期档案，关键是把 agent 输出纳入可追踪证据链，也提醒管理者先定义最小权限、回滚机制和人工签字点，而不是只看演示效果。
