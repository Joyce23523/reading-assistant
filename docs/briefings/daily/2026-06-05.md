# Morning Intelligence Briefing｜2026-06-05

## Top 3 Tech & AI Stories

### 1. Endava redesigns software delivery around AI agents
- **发生了什么**：Endava 采用 ChatGPT Enterprise、Codex 与 AI agents 重构软件交付流程，推动全企业 AI-native 文化建设。
- **为什么重要**：标志着大型 IT 服务商从「试点」转向「操作系统级」重构，AI agents 成为核心生产力单元，而非辅助工具。
- **对我有什么意义**：国际学校管理层可观察 enterprise AI adoption 的组织信号：工具链标准化、prompt literacy 成为基础技能、workflow 自动化向 agentic 迁移；A-Level 学生未来能力画像需包含 agent collaboration 与 verification 思维。
- **Source**：OpenAI Blog, 2026-06-04, https://openai.com/index/endava-frontiers

### 2. ChatGPT introduces "Dreaming" memory system
- **发生了什么**：OpenAI 发布新记忆机制 "Dreaming"，让 ChatGPT 跨对话保留偏好与上下文，保持相关性与新鲜度。
- **为什么重要**：长期记忆是 AI 从 stateless chat 向 personalized assistant 演进的关键基础设施，改变知识工作的连续性假设。
- **对我有什么意义**：个人知识系统可尝试将 "Dreaming" 与读书笔记、课程设计上下文绑定，减少重复 prompting；需追踪 privacy/retention 政策变化，作为 AI governance 观察点。
- **Source**：OpenAI Blog, 2026-06-04, https://openai.com/index/chatgpt-memory-dreaming

### 3. Meta AI customer support agent hijacked to steal Instagram accounts
- **发生了什么**：攻击者利用 Meta AI 客服 agent 将受害者 Instagram 账号绑定到攻击者控制的邮箱，实现账号劫持。
- **为什么重要**：暴露 AI agent 在身份验证、权限边界上的系统性脆弱性；AI security 不止模型层，更在 agent-tool 接口与授权逻辑。
- **对我有什么意义**：网络安全素养教学需纳入 "agent hijacking" 案例；学校账号体系若接入 AI client，必须审查 delegated authority 与 sandboxing 机制。
- **Source**：MIT Technology Review, 2026-06-05, https://www.technologyreview.com/2026/06/05/1138437/the-meta-hack-shows-theres-more-to-ai-security-than-mythos/
