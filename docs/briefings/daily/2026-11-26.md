## One Concept Explained
- **Concept / 概念**：Gemini API 的 Tool Retrieval 功能（生成式 AI 模型新增工具调用能力）
- **Plain explanation / 直白解释**：AI 模型可以直接调用外部工具获取实时信息、执行代码或访问专业数据库，而无需依赖固有知识库，这一能力使得 AI 从“静态问答”转向“动态行动”。
