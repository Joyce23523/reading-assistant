## Top 3 Tech & AI Stories

### 1. Perplexity and Intelligence — OpenAI
- **发生了什么**：OpenAI 发布文章解释 perplexity（困惑度）如何衡量 AI 模型进步，并提出开发者可用来评估新兴能力的共享方法。
- **为什么重要**：评估指标直接决定模型能力的可见性与治理优先级；困惑度作为统计语言模型的经典度量，重新被纳入 frontier AI 能力追踪，涉及统计推断与模型比较的基础设施。
- **对我有什么意义**：Joyce 可将 perplexity 作为 IAL Mathematics / Pure Mathematics 课堂中概率与统计模型评估的实例；关注学生对 AI 能力评估的 verification 与 prompt literacy 培养；记录 AI governance 中指标政治（metric politics）作为长期观察点。
- **Source**：OpenAI Blog, 2026-11-22, https://openai.com/index/perplexity-and-intelligence

### 2. Combatting adversarial distillation — OpenAI
- **发生了什么**：OpenAI 披露分层防御对抗性蒸馏（adversarial distillation），结合模型训练、防护、检测与执法，防止能力被提取（capability extraction）。
- **为什么重要**：模型知识产权与安全边界正从内容过滤扩展到能力保护，涉及 AI 治理、产业链竞争与跨境技术扩散的制度博弈。
- **对我有什么意义**：可纳入国际学校网络安全意识（cybersecurity awareness）与学生 AI 使用政策讨论；观察模型蒸馏检测如何影响校园 AI 工具采购与数据治理；作为 A-Level 学生未来能力画像中“模型安全素养”的参考。
- **Source**：OpenAI Blog, 2026-11-20, https://openai.com/index/combatting-adversarial-distillation

### 3. Introducing Tool Retrieval in the Gemini API — Google AI
- **发生了什么**：Google 推出 Gemini API 工具检索（Tool Retrieval），让模型能调用外部工具完成任务。
- **为什么重要**：工具使用（tool use）与检索增强生成正从演示转向可编程工作流，影响 AI agent 架构与学校自动化流程的可行性。
- **对我有什么意义**：参考构建跨模型自动化工作流（automation workflow）的底层能力；评估 Gemini API 在国际学校行政与教学知识管理中的可迁移性；关注 API 级工具调用对师生 prompt literacy 的要求。
- **Source**：Google AI Blog, 2026-11-20, https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/

## One Concept Explained

- **Concept / 概念**：Perplexity（困惑度）
- **Plain explanation / 直白解释**：Perplexity 是衡量语言模型对文本“困惑”程度的统计指标，数值越低表示模型对下一个词的预测越确定；OpenAI 提出将其作为评估新兴 AI 能力的共享参考。
- **Why it matters / 意义**：对教授概率与统计的教师而言，这是将模型评估带入课堂的具体切入点；也提醒学生，AI 能力不能只看单一分数，需结合 judgment 与 verification 进行多维度审视。
